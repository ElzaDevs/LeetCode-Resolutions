<h1> LeetCode Resolutions </h1>



Este é o meu espaço de prática com **algoritmos, estruturas de dados e resolução de problemas** usando o LeetCode.
A ideia deste repositório é simples: **não guardar apenas respostas prontas**.
Quero registrar o caminho até a solução — entender o problema, tentar resolver, descobrir onde errei, compreender a estrutura de dados utilizada e perceber por que uma solução é melhor que outra.
Assim, o código serve não só como resposta para o exercício, mas também como material de estudo para mim e para quem estiver aprendendo junto.
